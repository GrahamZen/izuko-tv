# 使用说明

[← 返回首页](../../README.md)

从海报浏览到播放控制，常用操作都可以用遥控器完成。

## 浏览

探索、搜索、追番和新番时间表中的海报，都支持下面几种打开方式。

<img src="images/browsing.svg" alt="海报浏览示意图：默认先看简介，用方向键选中海报，按一次确认显示背景大图和简介，再按一次确认进入详情页。也可以设置为直接播放（接着上次看到的那集，没看过则从第一集开始）或直接进详情页。设置位置：主题与色彩 → 海报上按确定。" width="780"/>

首次打开时，也能在引导最后一步「外观与操作」里选择海报的打开方式。

## 动作面板

<img src="images/action-panel.svg" alt="动作面板指南：在播放器以外长按返回键或播放键打开。1. 右上角扫码打开 Web 控制台，无需安装应用；2. 播放卡片确认继续观看，关闭按钮结束播放，没在播时显示接下来播放；3. 查看条目、搜索、背景图、图床的连通状态；4. 快捷按钮包含回主界面和退出应用，中间随页面变化，如刷新、换推荐和调整海报墙大小；5. 底部显示当前选中项的名称" width="780"/>

长按按键的作用可以在「设置 → 界面」里调整。

把缓存移到别的盘、导入收藏或从旧电视搬数据时，面板最上面显示进度；几件事同时在做时，选中那一格按确定看下一个。能停的任务右边有 ✕，按一下就停；搬缓存那条长按会打开「设置 → 存储」查看。

## 播放器

<img src="images/remote-player.svg" alt="播放器遥控器指南：上键打开选源；确认键播放或暂停，按住默认 2.5 倍速、松开恢复；左右键快退或快进 5 秒，按住或连按预览进度，确认跳转、返回取消；下键显示进度条与控制按钮，方向键在按钮间移动；返回键逐层收起，最后退出播放，长按直接回到画面；播放键播放或暂停，预览时从该位置播放；独立快退、快进键切换上一集、下一集" width="780"/>

退出播放页后，这一集会保留在后台，能播放时有气泡提示，回来不用重新找源；不需要的话在「设置 → 播放器和弹幕过滤」里关闭。

## 小提示

- **界面太大或太小**：「设置 → 界面 → 界面缩放」可以在 50% ~ 250% 之间调整。
- **电视上登录不方便**：扫登录页上的二维码，在手机上登录。
- **数据源排序**：在「设置 → 数据源管理」长按确认键拿起一行，上下键移动，确认键放下。添加和编辑数据源在 Web 控制台里。
- **网页验证码**（部分在线数据源需要）：用方向键移动页面中间的光标，移到边上会滚动页面，确认键点击；验证通过后一般会自动关闭，没关就长按确认键。
