## 下载

**第一次装、不知道下哪个，或者装的时候提示「解析错误」：** 先装[安装助手][github-installer]（`install-izuko.apk`，约 120 KB，Android 4.4 及以上都能装）。它按电视的系统版本和架构挑安装包，下载、校验后装上 Izuko TV，装不上时说明原因并列出诊断信息。已经装了 Izuko TV 的电视用应用内更新。其他装不上的情况见 [README 的「装不上怎么办」](https://github.com/$REPO_OWNER/izuko-tv#装不上怎么办)。

默认下载 `universal`（包含全部架构，体积最大）。个别盒子会拒装 `universal`（如腾讯极光盒子 7S），装不上时改下 `armeabi-v7a`，还不行再试 `arm64-v8a`。只有确切知道设备系统支持的架构时，才直接下对应的分架构包，体积更小、更省存储。注意芯片或设备信息里显示 64 位，不代表能装 64 位的包：不少电视和盒子的系统是 32 位的，装 `arm64-v8a` 会失败。

### Android 7.1 兼容包

表格里不带 `legacy` 的四个包要求 Android 8.1 及以上。装不上并提示 `INSTALL_FAILED_OLDER_SDK` 的话，改用带 `legacy` 的三个包（同样默认选 `legacy universal`），它们支持到 Android 7.1。用安装助手的话，它会自己挑。

兼容包和正式包功能一致，但只在少量设备上验证过；能装正式包就别用它。另外 Android 7.1 ~ 8.0 上 BT 引擎跑在应用进程内，退到后台被系统回收后下载不会保活。

## 本次更新

- 弹幕画在单独的一层上：开着弹幕时弹幕本身的 CPU 开销少约一半，选源面板盖在弹幕上时界面不再掉帧，打开面板时弹幕不再往回跳一下
- 弹幕出得更快：进播放页就开始找弹幕，通常开播前就已经准备好
- 边播边搜数据源时少做大量重复计算，拆开的季（如「夺还篇」）开播那一阵 CPU 占用降到约三分之一，打开选源面板补搜时也一样
- 订阅更新只更新数据源本身，你调过的顺序和启用 / 停用都保留；想跟着订阅排序，可在设置里打开「订阅更新时恢复订阅里的顺序」
- 「过滤贴片广告」默认关闭（现在几乎没有插广告的在线源），在线视频不再经过一层本地代理，需要时可在设置 - 播放器和弹幕过滤里打开
- Web 控制台播放卡的「全屏（同步播放）」：手机直接播电视正在放的这一集，进度跟着电视走，电视照常播放不受影响；在线源和电视上下完的缓存都能用（iPhone 播不了 mkv 时会直接说明）

- 第一次打开选源面板不再卡半秒
- 开过选源面板后再关掉，还在查的数据源会接着查完，不再每次关面板都打断、下次打开又从头查
- 网盘视频拖到没播过的位置时接着播得更快，跳转时不再常连到失效的下载节点
- 拖动预览停下后不再先闪过附近的画面，直接显示圆点那一帧
- 开着「边下边播」时少占一些内存
- 播放器里的详情页能打开这部番自己的详情页：在「显示更多」的弹窗里按「打开详情页」
- 修复重新搜索后，正在播的视频又重新加载一次
- 修复偶尔换集后卡住不动
- 修复部分字幕组 BD 合集的本地缓存点开后要等十几到几十秒才开始播
- 修复换集后，BT 源按系列名搜到的续作资源里找不到新的这一集
- 修复换集后播放正在缓存的 BT 资源时，又多建一条同样的缓存
- 修复播放中改搜索名后，新数据源查完时顶部的数据源变成「还没选出」
- 修复 Web 控制台缓存页勾「显示被排除的」时列出别的集的资源
- 修复播放页停着不动时，同一集的弹幕每小时重新加载一次
- 修复 Android 16 及以上的电视上，播放器菜单开着时按返回直接退出播放器，有时一下退两页
- 短时间内连着改十几部收藏时，提示「操作太频繁，请过几分钟再试」，不再报未知错误（Bangumi 限制每 5 分钟最多改 15 次）；把本地用户导入 Bangumi 时撞上这个限制会自动等一会儿接着导
- 「跟随系统」代理时，电视上提供代理的应用（VPN、加速器）关掉后几秒内就改回直连，不再一直连不上网；登录时连不上代理会直接提示是代理的问题
- 修复部分字幕组 mkv 的内封字幕显示成一串乱码；网盘里的外挂 ASS / SSA / WebVTT 字幕是 GBK、Big5 或 UTF-16 编码时也不再乱码
- 电视自己解不了的音频（TrueHD、DTS 等，常见于蓝光原盘）改用软件解码，不再只有画面没有声音
- 修复部分蓝光原盘播放出错：标了默认的音轨电视解不了（如 TrueHD）时，自动选同语言里能放的那一条；音轨列表里注明电视放不了的音轨，选它不会再把整个视频换掉
- 视频因为电视解不了它的音频或画面格式而播放失败时，提示里写明是哪种格式（如 TrueHD、AV1）；音轨全都解不了时提示只有画面没有声音，可以手动换个数据源
- 修复播放器里的详情页按左键会跳到关联条目，从关联条目按上会跳到页顶的「显示更多」
- 修复 Android 7.1 上兼容包在桌面和安装界面显示成默认的机器人图标
- 缓存网盘视频时一并存下旁边的外挂字幕，之后播缓存也有字幕
- 网盘视频缓存改为分段下载，一开始就能看到大小和进度；网络里有连不上的下载节点时，建缓存不再卡好几分钟

### 已知问题

* **画质增强（设置 - 播放器和弹幕过滤 - 默认画质增强模式）在电视上不可用，建议保持「关」**：Shield 上开启后只有声音没有画面，部分机型严重掉帧并很快卡住，需要强制停止应用恢复。
* 从 1.0.2 及更早的版本更新时，下载和安装还是旧版在做：如果点「去设置」后一直回到「去设置」，或 GitHub、ghfast 都连不上，请手动下载安装包覆盖安装（数据保留）。
